## 6. Розділ 5 — Теоретичне дослідження

**Сторінки:** 36-65 (найбільший розділ)

### 5.1 Аналіз моделей векторних ембеддінгів (стор. 36)

#### 5.1.1 TF-IDF (стор. 36)

**Що там:** базова формула, обмеження. Попередник BM25.

#### 5.1.2 Word2Vec (стор. 38)

**Що там:** статичні embeddings, word arithmetic.

#### 5.1.3 FastText (стор. 39)

**Що там:** підсловні n-grams, переваги для морфологічних мов.

#### 5.1.4 BERT (стор. 41)

**Що там:** трансформер, MLM, контекстуальні embeddings.

#### 5.1.5 Sentence-BERT (стор. 42)

**Що там:** адаптація BERT для семантичної схожості речень.

**Це важливо для:** літогляду на захисті, історичної перспективи.

### 5.2 Критерії оцінки моделей (стор. 44)

#### 5.2.1 Якість ранжування (nDCG) (стор. 45)

**Що там:** формула DCG, IDCG, нормалізація.

#### 5.2.2 Швидкість знаходження першого релевантного (MRR) (стор. 45)

**Що там:** Mean Reciprocal Rank, інтерпретація.

#### 5.2.3 Повнота пошуку (Recall) (стор. 46)

**Що там:** Recall@k формула.

#### 5.2.4 Точність пошукової видачі (Precision) (стор. 46)

**Що там:** Precision@k.

#### 5.2.5 Швидкодія пошуку (latency) (стор. 47)

**Що там:** Латентність як критерій. Чому важлива.

**Це важливо для:** питань про метрики.

### 5.3 Обґрунтування та опис задачі багатокритеріального вибору (стор. 47)

#### 5.3.1 Векторний опис альтернатив (стор. 49)

**Що там:** як представляється модель як вектор у просторі критеріїв.

#### 5.3.2 Перетворення шкал до єдиного напряму оптимізації (стор. 50)

**Що там:** **нормалізація** критеріїв. Min-max formula.

#### 5.3.3 Парето-оптимальні альтернативи (стор. 53)

**Що там:** Парето-домінування, формальне визначення, Парето-множина.

#### 5.3.4 Обґрунтування вибору загорткової моделі (стор. 55)

**Що там:** **Чому лінійна адитивна згортка** (vs TOPSIS, AHP).

#### 5.3.5 Визначення вагових коефіцієнтів (стор. 57)

**Що там:** Як обираються ваги, профілі по доменах.

#### 5.3.6 Розрахунок інтегральної оцінки (стор. 59)

**Що там:** Формула U(a), приклади розрахунку.

**Це важливо для:** питань про MCDA на захисті.

## Поради по швидкій навігації

### Розпакувати .docx для grep

```bash
python -m zipfile -e thesis/2026_М_ПІ_ІПЗм-24-1_Нестеренко_В_В.docx /tmp/docx
```

Тепер можна grep:
```bash
grep -i "bge-m3" /tmp/docx/word/document.xml
```

### Використати doc_text.txt

`thesis/doc_text.txt` — повний текст записки. Швидко знайти:
```bash
grep -n "nDCG" thesis/doc_text.txt
```

### Кеш-стратегія для захисту

1. **На столі** — паперова чи цифрова копія записки з закладинками на:
   - Розділ 5.2 (метрики)
   - Розділ 5.3 (MCDA)
   - Розділ 6.4 (результати)
   - Висновки
2. **На екрані** — застосунок, готовий до демо
3. **У голові** — основні цифри (з файлу 14_numbers.md)
